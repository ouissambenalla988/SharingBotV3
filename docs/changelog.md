# Changelog

Toutes les modifications notables de ce projet seront documentées dans ce fichier.

Le format est basé sur [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
et ce projet adhère au [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2025-02-24

### Ajouté
- ✨ Système de chat complet avec historique persistant
- 🎙️ Reconnaissance vocale (ASR) intégrée
- 🔊 Synthèse vocale (TTS) pour les réponses
- 📄 Système RAG avec upload de documents PDF
- 🖼️ OCR pour extraction de texte depuis les images
- 💾 Persistance automatique dans Supabase
- 📱 Sidebar de navigation des conversations
- 🌍 Support multilingue amélioré
- 🎨 Interface modernisée avec Shadcn UI

### Modifié
- ⬆️ Mise à jour vers Next.js 15
- ⬆️ Mise à jour vers TailwindCSS v4
- ⬆️ Mise à jour vers ESLint v9
- 🎨 Amélioration du thème sombre
- 📦 Optimisation des dépendances
- 🏗️ Refactoring de l'architecture monorepo

### Corrigé
- 🐛 Corrections mineures portées depuis le kit complet
- 🔒 Amélioration de la sécurité RLS
- 🚀 Optimisations de performance

## [0.1.0] - 2024-12-19

### Ajouté
- 🎉 Version initiale du Next.js Supabase SaaS Kit Lite
- 🏗️ Configuration Turborepo monorepo
- 🔐 Authentification Supabase complète
- 👤 Gestion des profils utilisateurs
- 📱 Pages marketing responsive
- 🔒 Routes protégées
- 🎯 Configuration de base des tests avec Playwright
- 🌐 Support i18n (client + serveur)
- ✨ Configuration TypeScript stricte
- 🎨 Composants Shadcn UI
- 💅 TailwindCSS v4
- 🔧 ESLint v9 + Prettier
